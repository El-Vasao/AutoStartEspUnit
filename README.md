# AutoStartEspUnit

## Руководство по эксплуатации

Изделие: блок удалённого автозапуска автомобиля.  
Аппаратная основа: модуль ESP32-C3 (**XH-C3F**, посадочное место ESP-12), модем SIM800.

---

## 1. Назначение

Изделие предназначено для удалённого и автоматического управления исполнительными цепями автомобиля (зажигание, стартер, ACC, обход иммобилайзера и связанные реле), а также для контроля состояния входов, температуры и напряжения бортсети.

Изделие обеспечивает:

а) исполнение программ пуска и останова двигателя;  
б) приём команд по телефонному вызову (DTMF) и по протоколу MQTT;  
в) автоматический запуск программ по условиям (триггеры, термостат, защита аккумуляторной батареи);  
г) настройку и обновление программного обеспечения через собственную точку доступа Wi‑Fi.

Облачный сервис производителя не предоставляется. SIM-карта, MQTT-брокер и номер телефона задаются при настройке.

Изделие не является готовым комплектом под конкретную модель автомобиля. Подключение датчиков, полярность входов и содержание программ определяются при установке.

---

## 2. Внимание!

Перед началом эксплуатации необходимо убедиться в правильности подключения цепей стартера, зажигания и блокировки пуска.

**Запрещается:**

а) подавать команды пуска двигателя при неподключённом или неисправном входе блокировки, если блокировка задана в настройках;  
б) допускать посторонних лиц к точке доступа Wi‑Fi изделия (веб-интерфейс и обновление прошивки отдельной авторизации не имеют);  
в) снимать питание изделия во время обновления программного обеспечения;  
г) включать защиту аккумуляторной батареи и термостат при неполной настройке (устройство отклонит включение).

При длительном хранении вне автомобиля рекомендуется сохранять копию настроек (экспорт с вкладки «Система»).

## 4. Устройство и принцип работы

### 4.1. Программы

Программа представляет собой упорядоченную последовательность шагов.

Правила исполнения:

1. Одновременно может выполняться только одна программа.  
2. При успешном запуске другой программы во время исполнения текущей реле стартера отключается; состояние остальных реле сохраняется.  
3. Если программу запустить не удалось (файл отсутствует, программа пуста либо шаги не прошли проверку), все реле отключаются.  
4. По нормальному завершению программы реле не отключаются.  
5. Команда остановки отключает все реле только в том случае, если программа ещё выполняется. После успешного завершения пуска для отключения реле должна быть запущена программа «Стоп» либо эквивалентная ей.

### 4.2. Шаги программы

Длительность в интерфейсе задаётся в секундах.

| Наименование шага | Параметры | Назначение |
|-------------------|-----------|------------|
| Пауза | длительность | Выдержка заданного интервала |
| Включить / Выключить / Переключить | реле | Управление одним реле (кроме START) |
| Импульс вкл→выкл→вкл | реле, длительность | Вкл — пауза — выкл — пауза — вкл |
| Импульс выкл→вкл→выкл | реле, длительность | Выкл — пауза — вкл — пауза — выкл |
| Запуск двигателя | — | Автомат пуска стартера (п. 4.3) |
| Включить / Отключить вход | вход | Изменение состояния входа только на время работы |
| Включить / Выключить триггер по входу | триггер | Управление входным триггером |
| Включить / Выключить триггер по температуре | триггер | Управление температурным триггером |
| Включить / Выключить защиту АКБ | — | Включение допускается только при готовности изделия |
| Включить / Выключить термостат | — | Включение допускается только при готовности изделия |
| Звонок владельцу | — | Исходящий вызов на номер из настроек. Состояния «занято» и «не отвечает» не прерывают программу при успешном сбросе вызова |
| SMS владельцу | текст не более 64 символов, латиница | Отправка SMS на тот же номер. Пустой текст сохранению не подлежит |

### 4.3. Запуск двигателя

Единственный способ включения реле START. Параметры задаются в настройках автомобиля и в состав шага не входят.

| Наименование параметра | Значение по умолчанию |
|------------------------|------------------------|
| Реле стартера | K3 |
| Способ пуска | по времени (также: по оборотам; по входу) |
| Время прокрутки | 2 с |
| Максимальное время прокрутки | 5 с (принудительное отключение реле стартера, в том числе при зависании программы) |
| Пауза после прокрутки | 10 с |
| Пауза между попытками | 5 с |
| Число попыток | 3 |
| Порог «заведён» / «заглушен» | 13,2 / 12,8 В |
| Вход блокировки | IN2 |

Правила:

а) если вход блокировки задан, он должен быть исправен, включён и логически неактивен; в противном случае пуск запрещён;  
б) активная блокировка на любой фазе попытки отключает реле стартера;  
в) прокрутка не производится, если уже установлен признак «двигатель работает». Источник признака задаётся отдельно: по напряжению (гистерезис «заведён»/«заглушен») или по входу. При источнике «вход» признак наследует состояние выбранного входа; если тот же вход используется способом пуска по входу/оборотам, условие до прокрутки с признаком совпадает. При источнике «напряжение» и пуске по времени критерии разные: признак — гистерезис, успех без прокрутки возможен также по полному окну напряжения не ниже «заведён»;  
г) после прокрутки при пуске по времени успех шага признаётся только при полном окне напряжения не ниже порога «заведён» (это не то же самое, что признак «двигатель работает» на панели);  
д) обрыв цепи или отказ включения реле стартера прерывает шаг; повторное включение допускается после паузы;  
е) смена идентификатора реле стартера во время прокрутки откладывается;  
ж) прямое включение реле START через веб-интерфейс или MQTT не допускается;  
з) при отказе попытки или срабатывании блокировки все реле отключаются; на паузе между попытками реле IGN и BYPASS сохраняют состояние.

Последовательность попытки: контроль блокировки → прокрутка (при необходимости) → оценка результата → повтор либо отказ.

### 4.4. Триггеры

Предусмотрено до восьми триггеров по входам и до восьми — по температуре. По умолчанию триггеры выключены.

| Правило | Норма |
|---------|-------|
| Срабатывание | однократно при переходе условия в истинное состояние |
| Повторный запуск | после отпускания условия |
| После включения питания и после обновления прошивки | уже истинное условие программу немедленно не запускает |
| Триггер выключен или программа не задана | запуск не производится |

**Триггер по входу.** Задаются вход, требуемый уровень (активен / неактивен) и программа. Отключённый вход рассматривается как неактивный.

**Триггер по температуре.** Задаются датчик, условие «выше» или «ниже» порога и программа. Повторное вооружение выполняется после возврата температуры за порог на 0,5 °C. Неисправное показание датчика условие не отпускает.

Привязки по умолчанию:

| Канал | Условие | Программа |
|-------|---------|-----------|
| IN1 Brake pedal SW | активен | «Стоп» |
| IN3 Button | активен | «Запуск» |
| T1 Cabin | ниже −10 °C | «Запуск» |
| T2 Engine | выше 105 °C | «Стоп» |
| T3 Outside | ниже −15 °C | «Запуск» |

Вход IN2 служит блокировкой пуска и триггером программы не является. Неисправная ссылка триггера на отсутствующую программу циклического отключения всех реле не вызывает.

### 4.5. Термостат

Термостат не тождественен температурным триггерам. Контролируется один датчик; задаются нижний и верхний пороги и отдельная программа для каждого порога.

| Условие | Действие |
|---------|----------|
| Температура ниже нижнего порога | запуск нижней программы |
| Температура выше верхнего порога | запуск верхней программы |
| Гистерезис отпускания | 0,5 °C |
| Одновременное выполнение обоих порогов | исполняется верхняя программа |
| Включение | допускается только при готовности (датчик выбран, верхний порог выше нижнего, задана хотя бы одна программа) |
| Выключение | допускается всегда |
| Признак «активен» в настройках | намерение включить термостат после перезагрузки при наличии готовности |

По умолчанию: датчик T1 Cabin, пороги −15 / 10 °C, программы «Запуск» / «Стоп», термостат выключен.

### 4.6. Защита аккумуляторной батареи

Функция обеспечивает автоматический пуск при длительной просадке напряжения бортсети и аварийное отключение всех реле при критически низком напряжении после пуска.

| Наименование параметра | Значение по умолчанию |
|------------------------|------------------------|
| Порог пуска | 11,8 В |
| Порог обрыва | 10,5 В (должен быть ниже порога пуска) |
| Гистерезис | 0,5 В |
| Минимальная длительность просадки | 180 с |
| Пауза между попытками | 1800 с |
| Число попыток в сутки | 3 |
| Программа | «Запуск» |

| Напряжение бортсети U | Поведение |
|-----------------------|-----------|
| U ниже порога пуска | таймер просадки идёт (только при отсутствии выполняющейся программы) |
| от порога пуска до порога плюс гистерезис | таймер остановлен, пуск не производится |
| U выше порога плюс гистерезис | таймер сбрасывается |

а) успешный пуск учитывается в суточном лимите; неуспешный — не учитывается, таймер просадки начинается заново;  
б) сутки — календарный день при синхронизированных часах, иначе интервал 24 часа с момента включения;  
в) если после пуска напряжение снизилось ниже порога обрыва, выполняется программа данной функции, текущий шаг не является «Запуском двигателя» и признак «двигатель работает» не установлен — программа останавливается, все реле отключаются;  
г) включение функции допускается только при готовности изделия.

### 4.8. Режимы работы

Наименования режимов соответствуют индикатору «Режим работы» в шапке интерфейса.

| Режим работы | Состав функций | Модем | Точка Wi‑Fi |
|--------------|----------------|-------|-------------|
| Настройка | входы, датчики, признак «двигатель работает», защита реле START по времени; программы, триггеры, термостат и защита АКБ не исполняются | выключен | поднята |
| Норма | полный контур | включён | поднята |
| Тихий | как в режиме «Норма» | включён | погашена; возврат — входом IN3 или командой MQTT |
| Авария | только веб-интерфейс; реле не обслуживаются | выключен | поднята |
| Прошивка | при входе: остановка программы, отключение реле, выключение автоматических функций | пауза | поднята (страница состояния загрузки) |

Также могут отображаться: **«Нужна перезагрузка»** (после сохранения настроек; режим до перезагрузки прежний) и **«Загрузка»** (после подачи питания).

## 5. Подготовка к работе и эксплуатация

### 5.1. Первичная настройка

1. Подключиться к точке доступа `AutoStart-Setup`.  
2. Задать параметры Wi‑Fi, номер телефона, пароль DTMF, брокер MQTT и параметры автомобиля.  
3. Привязать датчики температуры (ROM).  
4. Сохранить настройки и выполнить перезагрузку.

В режиме первичной настройки модем выключен. Если конфигурацию поднять не удалось, изделие переходит в аварийный режим: веб-интерфейс доступен, модем и реле не обслуживаются.

### 5.2. Обслуживание

Изделие обеспечивает:

а) экспорт и импорт настроек и программ;  
б) перезагрузку устройства и модема;  
в) возврат к значениям по умолчанию;  
г) обновление программного обеспечения файлом `.bin` с вкладки «Система».

На время обновления прошивки текущая программа останавливается, реле отключаются, триггеры и автоматические функции выключаются, модем приостанавливается. Снятие питания в процессе обновления **не допускается**.

Журналы системы и модема ведутся при открытой странице интерфейса.

Подробные операционные сценарии — в [docs/USAGE.md](docs/USAGE.md).
